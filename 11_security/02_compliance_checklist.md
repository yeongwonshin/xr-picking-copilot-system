# Compliance Checklist

## 개인정보
- [ ] 카메라 사용 고지문 게시
- [ ] 작업자 동의/노사 협의 절차 검토
- [ ] 원본 영상 저장 여부와 보존기간 명시
- [ ] 얼굴·음성 등 생체정보 처리 여부 검토
- [ ] 고객사별 데이터 처리 위탁 계약 체결

## 보안 통제
- [ ] SSO/MFA 적용
- [ ] RBAC 역할 설계
- [ ] 관리자 작업 감사 로그
- [ ] API rate limit
- [ ] 취약점 스캔과 정기 침투 테스트
- [ ] 백업/복구 훈련

## AI 거버넌스
- [ ] 모델 버전별 성능 기록
- [ ] 오차단/오통과 샘플 리뷰
- [ ] 학습 데이터 출처 기록
- [ ] 고객사 데이터 경계 유지
- [ ] 모델 rollback 절차

## 현장 안전
- [ ] PPE와 글래스 착용 호환성 확인
- [ ] UI가 시야를 가리지 않는지 현장 검증
- [ ] 위험 구역 알림 정책
- [ ] 디바이스 발열/배터리 관리
- [ ] 비상 상황에서 글래스 사용 중단 절차
