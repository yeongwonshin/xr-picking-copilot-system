# Acceptance Tests

## 기능 테스트
| ID | 시나리오 | 기대 결과 |
|---|---|---|
| AT-001 | 작업자 로그인 | 세션 생성, 권한별 메뉴 표시 |
| AT-002 | 다음 작업 요청 | 우선순위에 맞는 XRTaskCard 수신 |
| AT-003 | 올바른 위치 스캔 | LOCATION_SCAN PASS |
| AT-004 | 잘못된 위치 스캔 | 경고, 완료 차단 |
| AT-005 | 올바른 SKU 스캔 | SKU_SCAN PASS |
| AT-006 | 잘못된 SKU 스캔 | FAIL, 재스캔 요청 |
| AT-007 | 수량 부족 입력 | WARN 또는 예외 플로우 |
| AT-008 | 토트 불일치 | 완료 차단 |
| AT-009 | 재고 없음 음성 명령 | ExceptionCase 생성 |
| AT-010 | WMS 장애 중 완료 | 로컬 큐 저장 후 재전송 |

## 성능 테스트
- 동시 작업자 100명, 초당 검증 이벤트 500건
- 검증 p95 500ms 이하
- WMS 지연 10초 상황에서 앱 UX 유지
- Edge Node 재시작 후 이벤트 손실 없음

## 현장 UAT
- 1일 이상 실제 웨이브 피킹 운영
- 작업자 5명 이상 설문
- 관리자 콘솔 알림 정확도 검증
- 배터리 교체와 충전 스테이션 운영 검증
