# Pilot Success Metrics

## 베이스라인 측정
파일럿 전 2주 동안 아래 지표를 측정한다.
- 월/일 피킹 라인 수
- 오류율: 오피킹, 누락, 수량, 포장 오류
- 시간당 라인 처리량
- 신규 작업자 교육 시간
- 재작업/CS 비용
- 작업자 이동거리 추정

## 파일럿 지표
| 지표 | 목표 |
|---|---|
| 시스템 가동률 | 99% 이상 |
| 작업자 착용 지속률 | 80% 이상 |
| 피킹 라인 처리량 | 10% 이상 개선 또는 동등 이상 |
| 오류율 | 30% 이상 개선 추세 |
| 재스캔률 | 5% 이하 권장 |
| AI 오차단률 | 1% 이하 목표 |
| WMS 이벤트 누락 | 0건 |

## 파일럿 실패 조건
- 글래스 착용 피로로 작업자 거부가 높음
- Wi-Fi 음영으로 세션이 자주 끊김
- SKU 마스터/바코드 품질이 낮아 검증이 지연됨
- WMS 확정 지연 또는 중복 처리 위험이 큼
- 관리자 개입이 과도하게 늘어남

## Go/No-Go 의사결정
- KPI 개선이 명확하면 Professional Rollout
- UX는 좋지만 AI 정확도가 낮으면 바코드-first 모드로 확대 후 AI 데이터 축적
- 인프라 문제가 크면 네트워크/라벨 개선 후 재파일럿
