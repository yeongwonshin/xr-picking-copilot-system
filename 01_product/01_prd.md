# Product Requirements Document

## 제품명
XR Picking Copilot

## 제품 목표
창고 작업자가 스마트글래스 기반 시야 안내와 AI 검증을 통해 빠르고 정확하게 피킹·검수·포장을 수행하도록 지원한다.

## 주요 사용자
- Picker: 피킹 작업자
- Packer: 포장 작업자
- Supervisor: 현장 관리자
- WMS Admin: 시스템 관리자
- QA/Audit Manager: 품질·감사 담당

## 핵심 기능
### 1. 작업 할당
- WMS 작업 큐 수신
- 작업자 숙련도, 현재 위치, 존, 우선순위 기반 할당
- 배치/웨이브/싱글오더/멀티오더 피킹 모드 지원

### 2. XR 안내
- 다음 로케이션, SKU, 이미지, 수량, 토트/박스 ID 표시
- 통로/존 기반 경로 안내
- 완료·건너뛰기·문제신고 음성 명령
- 시야 방해 최소화를 위한 HUD 레이아웃

### 3. 검증
- 바코드/QR 스캔 검증
- 카메라 기반 SKU 시각 검증
- 로케이션 QR/마커 검증
- 수량/토트/포장 순서 검증
- 위험 경고: 지게차 동선, 금지구역, 피로/과부하 알림은 확장 모듈

### 4. 예외 처리
- SKU 없음
- 재고 부족
- 위치 불일치
- 라벨 훼손
- 유사 SKU 혼동
- 디바이스 연결 끊김
- WMS 응답 지연

### 5. 관리자 콘솔
- 작업 현황 보드
- 작업자·디바이스 상태
- 오류 히트맵
- SKU별 오피킹 리스크
- 실시간 알림 및 작업 재할당

## 비기능 요구사항
- 글래스 UI 반응: 200ms 이내 목표
- 스캔 후 검증 결과: 500ms 이내 목표
- WMS 이벤트 반영: 3초 이내 목표
- Edge AI 추론: 100ms~300ms 목표, 네트워크 상태에 따라 로컬/서버 전환
- 오프라인 모드: 최소 30분 작업 큐 캐시
- 개인정보: 작업자 얼굴·음성 원본 최소 저장, 기본 비식별화

## 제외 범위 v1
- 완전 자율 로봇 피킹
- 실내 정밀 AR SLAM 기반 3D 내비게이션 전면 적용
- 모든 SKU에 대한 100% 비전 식별 보장
- ERP 마스터 데이터 품질 개선 대행
