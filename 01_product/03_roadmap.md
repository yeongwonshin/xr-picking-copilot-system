# Roadmap

## Phase 0 — Discovery & Site Audit
- 창고 레이아웃, 로케이션 라벨, 조도, Wi-Fi, WMS API 확인
- 상위 500개 SKU의 유사도/오류 위험 분석
- 현행 피킹 시간, 오류율, 재작업 비용 베이스라인 측정

## Phase 1 — Pilot
- 단일 존, 5~10명 작업자, 2~4주 운영
- WMS 작업 수신, 글래스 안내, 바코드 검증, 기본 콘솔
- 성공 기준: 시스템 안정성, 작업자 수용도, 오류율 개선 추세

## Phase 2 — Professional Rollout
- 다중 존, 웨이브 피킹, 토트 검증, 포장 검증
- Edge AI SKU 검증 모델 적용
- 관리자 콘솔과 KPI 리포트 고도화

## Phase 3 — Enterprise Scale
- 멀티창고, SSO/SAML, 전용 VPC, 고가용성
- 디바이스 MDM, OTA 업데이트, 장애 자동복구
- 모델 드리프트 감시, SKU별 리스크 스코어링

## Phase 4 — Optimization Layer
- 동적 경로 최적화
- 슬롯팅 추천
- 인력 배치 추천
- 작업자 피로도와 안전 리스크 기반 작업 조정
