# User Journeys

## Picker Journey
1. 작업자 로그인: 사원증 QR 또는 SSO PIN
2. 디바이스 점검: 배터리, 네트워크, 카메라, 마이크, 렌즈 상태
3. 작업 할당: “오늘의 우선 웨이브 #A-102” 수신
4. 로케이션 이동: 시야에 존, 통로, 랙, 빈 표시
5. 위치 확인: 로케이션 QR 스캔 또는 카메라 마커 확인
6. 상품 확인: 바코드/QR 스캔 + SKU 이미지 비교
7. 수량 확인: 음성 “두 개 완료” 또는 손동작/스캔 반복
8. 토트 투입: 토트 ID 확인
9. 예외 처리: “재고 없음”, “라벨 불량”, “관리자 호출”
10. 완료: WMS에 작업 라인 완료 이벤트 전송

## Packer Journey
1. 토트 수신
2. 주문별 포장 순서 표시
3. 취급주의/냉장/동봉물/송장 지시 확인
4. AI가 잘못된 박스 크기 또는 누락 SKU 리스크 알림
5. 포장 완료 및 송장 스캔

## Supervisor Journey
1. 실시간 작업 상태 확인
2. 지연/오류 발생 작업자 확인
3. 존별 병목 히트맵 확인
4. SKU 위치 변경 또는 우선순위 재할당
5. 하루 KPI 리포트 자동 생성

## WMS Admin Journey
1. 창고/존/로케이션 마스터 업로드
2. WMS 커넥터 설정
3. SKU 이미지·바코드·패키지 정보 매핑
4. 이벤트 매핑 테스트
5. 권한·감사 로그 설정
