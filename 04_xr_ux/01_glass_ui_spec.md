# XR Glass UI Specification

## UI 원칙
- 작업자의 중심 시야를 가리지 않는다.
- 한 화면에는 하나의 결정만 요구한다.
- 색상 의존 경고를 피하고 텍스트·아이콘·음성 피드백을 병행한다.
- 걸어가는 중에는 세부 정보를 줄이고, 로케이션 도착 후 상세 검증 화면을 보여준다.

## 기본 HUD 카드
```text
┌──────────────────────────────┐
│ 다음 위치: A-03-02-B          │
│ SKU: 8801234567890            │
│ 상품: 스킨케어 세트 50ml       │
│ 수량: 2 EA                    │
│ 토트: TOTE-17                 │
│ 명령: 스캔 / 완료 / 문제       │
└──────────────────────────────┘
```

## 경고 화면
```text
⚠ 잘못된 상품 가능성
예상 SKU: 8801234567890
스캔 SKU: 8801234567001
조치: 다시 스캔하거나 관리자 호출
```

## 포장 화면
```text
주문 ORD-2026-00082
1) 완충재 1장
2) SKU A x 2
3) SKU B x 1
4) 냉장 스티커 부착
5) 송장 스캔
```

## 음성 피드백
- 성공: 짧은 효과음 + “확인됨”
- 경고: 진동 + “다시 확인하세요”
- 실패: 진동 2회 + 경고 카드 고정

## 접근성
- 좌/우 눈 디스플레이 위치 선택
- 글자 크기 3단계
- 소음 환경을 위한 버튼/제스처 fallback
- 다국어 작업자 지원: 한국어, 영어, 베트남어 등 확장 가능
