# Epics & User Stories

## Epic 1 — XR Picking
- 작업자로서 다음 로케이션과 SKU를 시야에서 확인하고 싶다.
- 작업자로서 음성으로 완료/문제/다음을 입력하고 싶다.
- 작업자로서 네트워크가 끊겨도 현재 작업을 계속하고 싶다.

## Epic 2 — Verification
- 시스템으로서 잘못된 SKU 스캔을 즉시 차단해야 한다.
- 시스템으로서 AI 신뢰도가 낮은 경우 재스캔을 요청해야 한다.
- 관리자로서 오류가 많이 나는 SKU를 확인하고 싶다.

## Epic 3 — WMS Integration
- WMS 관리자로서 작업 완료 이벤트를 중복 없이 받고 싶다.
- WMS 관리자로서 재고 부족 예외를 WMS에 자동 반영하고 싶다.
- IT 관리자로서 연동 실패 이벤트를 replay하고 싶다.

## Epic 4 — Ops Console
- 관리자로서 작업자별 진행률과 지연 작업을 보고 싶다.
- 관리자로서 글래스 배터리와 연결 상태를 확인하고 싶다.
- 품질 담당자로서 오류 히트맵과 SKU별 리스크를 보고 싶다.

## Epic 5 — Security & Governance
- 보안 담당자로서 모든 관리자 설정 변경을 감사 로그로 보고 싶다.
- 테넌트 관리자로서 역할별 접근 권한을 제한하고 싶다.
- 개인정보 담당자로서 영상 저장 여부와 보존기간을 제어하고 싶다.

## Epic 6 — AI Model Operations
- ML 엔지니어로서 SKU 모델 버전을 관리하고 싶다.
- ML 엔지니어로서 오차단 샘플을 라벨링 큐로 보내고 싶다.
- 운영자로서 모델 배포 후 오류율이 증가하면 rollback하고 싶다.
