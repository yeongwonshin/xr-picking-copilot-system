# Sales Playbook

## 발견 질문
- 현재 월 피킹 라인 수는?
- 오피킹/누락/포장 오류율과 비용은?
- 작업자 교체율과 교육 기간은?
- WMS는 무엇을 사용하고 API 접근이 가능한가?
- 로케이션 라벨과 SKU 바코드 품질은?
- Wi-Fi 음영, 조도, 소음 문제는?
- PDA/Voice/Pick-to-Light를 이미 쓰는가?

## 데모 시나리오
1. WMS에서 작업 생성
2. 글래스에 다음 위치 표시
3. 위치 QR 스캔
4. 올바른 SKU 스캔 → 즉시 완료
5. 잘못된 SKU 스캔 → 경고
6. 재고 없음 음성 명령 → 관리자 콘솔 알림
7. 포장 검증과 KPI 대시보드 확인

## 반박 처리
### “스마트글래스가 불편하지 않나?”
단일 전사 도입이 아니라, 오류 비용이 높은 존부터 착용 테스트와 피로도 평가를 진행한다. 음성/스캐너 fallback을 제공한다.

### “WMS 모바일 앱으로 충분하지 않나?”
WMS 모바일 앱은 작업 지시와 확정에는 강하지만, 작업자 시야 안내와 카메라 기반 오피킹 검증은 제한적이다.

### “AI가 틀리면 작업이 막히지 않나?”
AI는 단독 판정자가 아니라 바코드, 위치, 수량, 작업 맥락과 결합한다. 낮은 신뢰도는 재스캔·샘플링 검수로 처리한다.

## PoC 성공 기준 합의
- 오류율 개선
- 작업자 만족도
- WMS 반영 안정성
- 글래스 착용 지속성
- 관리자 운영 부담
- 장비 유지관리 난이도
